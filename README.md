# Introduction à NumPy, Pandas et Matplotlib

Notebooks d'introduction pour l'analyse de données en Python.
Installations requises:
- Python
- Jupyter lab pour l'environnement
- Git pour cloner

## Parcours conseillé

NumPy (1 → 3), puis pandas (1 → 3), puis Matplotlib (1 → 2, et 3 en option).

| Notebook | Contenu |
|---|---|
| NumPy 1 | Création d'arrays |
| NumPy 2 | Indexation, slicing, masques |
| NumPy 3 | Agrégation, broadcasting |
| pandas 1 | Lecture (`read_csv`) et exploration |
| pandas 2 | Masques, `loc` / `iloc` |
| pandas 3 | `groupby`, `merge`, `concat` |
| Matplotlib 1 | `plot` et `scatter` |
| Matplotlib 2 | Mise en forme, `subplots`, barres |
| Matplotlib 3 *(option)* | Histogrammes, boxplots, heatmaps |

## Données (`data/`)

| Fichier | Description |
|---|---|
| `titanic.csv` | 891 passagers du Titanic (jeu de données classique) |
| `ports.csv` | codes des ports d'embarquement (pour le `merge`) |
| `temperatures.csv` | températures mensuelles moyennes approximatives de 3 villes françaises (illustratif) |
